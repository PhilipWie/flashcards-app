# flashcards-app

> Karteikarten Web-App um das lernen mit Karteikarten zu vereinfachen und digitalisieren.<br>
> Die Web-App dient dazu neue Karteikarten einfach online zu erstellen, in Ordnern zu organisieren und zu lernen.
